# 70. Climbing Stairs

You reach the nth stair in two possible ways:
* From n-1 by taking 1 step
* From n-2 by taking 2 steps

So the number of ways to reach step n is:
```ways(n) = ways(n-1) + ways(n-2)```

-which is like Fibonacci series

```
class Solution {
public:
    int climbStairs(int n) {
        int a = 1, b = 1;
        for(int i = 2; i <= n; ++i) {
            int temp = a + b;
            a = b;
            b = temp;
        }
        return b;
    }
};
```
