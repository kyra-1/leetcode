1.) ##unordered map:   
we intialised an unordered map as ```unordered_map<int,int> seen``` and also included library as ```#include<unordered_map>``` 

## 🌟 What’s in the `unordered_map`?

It's like a counter:

* **Key** = number from the array
* **Value** = how many times we’ve seen it so far

---

## 🧠 What does `if (seen[num] > 0)` mean?

It checks:

> "Have I seen this number before?"

If **yes** (`seen[num] > 0`), then it's a **duplicate**!

🔁 **Note:**

* We check **before** increasing the count.
* That’s how we catch the duplicate right when it repeats.

---

## 👀 Example Walkthrough

Array: `[1, 2, 3, 1]`

| Step | Num | Check `seen[num] > 0` | Map After Step     |
| ---- | --- | --------------------- | ------------------ |
| 1    | 1   | 0 > 0? ❌ (no)         | {1: 1}             |
| 2    | 2   | 0 > 0? ❌ (no)         | {1: 1, 2: 1}       |
| 3    | 3   | 0 > 0? ❌ (no)         | {1: 1, 2: 1, 3: 1} |
| 4    | 1   | 1 > 0? ✅ (yes!) → dup | return true        |

At step 4, we hit a repeat of `1` and `seen[1] == 1` **before** incrementing.

---

## 🧩 Quick Quiz:

> ❓ When does `seen[num]` become 2?

💡 After the **second appearance** — but we catch the duplicate **at 1**.

```
#include <unordered_map>
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {
        unordered_map<int, int> seen;
        for (int num : nums) {
            if (seen[num] > 0) return true;
            seen[num]++;
        }
        return false;
    }
};
```

2.) sorting

we sort the array and check adjacent values, as soon as theres a match we return true;
```
#include<unordered_map>
class Solution {
public:
    bool containsDuplicate(vector<int>& nums) {   int n=nums.size();
    sort(nums.begin(),nums.end());
    //for(auto& num:nums){cout<<num;}
    for(int i=0;i<n-1;i++){
        if(nums[i]==nums[i+1])return true;
    }
    return false;
        
    }
};
```
